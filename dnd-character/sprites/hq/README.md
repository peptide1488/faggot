# HQ art pack

Generated / hand-authored chunky pixel sprites used by Grimoire Iso3D.

- **Terrain** — sliced from `iso3d-engine` voxel `atlas.png` (`tools/import_voxel_terrain.py`)
- **Units & decor** — `tools/gen_pixel_sprites.py`

Missing class/monster keys fall back to fighter / goblin stand-ins.
