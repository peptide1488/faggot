# HQ pack — FFT-inspired (generated)

Original art generated for Grimoire (not ripped from Final Fantasy Tactics).

| Path | Content |
|------|---------|
| `characters/fighter.png` | Knight (4×4 sheet; walk frames when multi-pose art is ready) |
| `characters/paladin.png` | Alias / variant |
| `characters/barbarian.png` | Alias / variant |
| `characters/human.png` | Alias / variant |
| `monsters/goblin.png` | Goblin spearman |
| `decor/*_px.png` | Pixelized billboard trees/bushes |
| `terrain/*.png` | Seamless 128×128 ground tiles |

`SPRITE_PACK = 'hq'` in `iso3d/src/adapter.js` selects this pack for units (default).

Missing class/monster keys fall back to fighter/goblin HQ stand-ins so the field stays FFT-style — not RPM Paper Maker.
