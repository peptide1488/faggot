# Highland Meadow — edge and connection spec

Generated by `socket_spec.py` from `out/grass10A/tiles.json`. Do not hand-edit: re-run it after any change to the tile table.

**The rule:** two tiles may abut iff the facing sockets are equal. Everything below is a consequence of that rule and the pieces that exist.

## Vocabulary

`faces` counts (tile x rotation x edge) instances, so it measures how much freedom the solver has when a neighbour demands that socket.

| socket | meaning | faces | families that present it |
|---|---|---:|---|
| `G0` | ground, low band | 160 | mire, ramp, scarp, shoal, strand, track, turf |
| `G1` | ground, high band | 92 | bluff, ramp, scarp, turf |
| `W` | open water | 60 | bluff, mere, shoal, strand |
| `G0+P` | ground low, with a track crossing this edge | 56 | ford, track |
| `Xw0` | a level change crosses this edge (water <-> low) | 40 | ford, shoal, strand |
| `X01` | a level change crosses this edge (low <-> high) | 40 | ramp, scarp, track |
| `Xw1` | a level change crosses this edge (water <-> high) | 24 | bluff |
| `W+P` | water, with a track crossing this edge (a ford) | 4 | ford |
| `G1+P` | ground high, with a track crossing this edge | 4 | track |

**Thin:** `G1+P`, `W+P` — four faces or fewer. A neighbour demanding one of these leaves the solver a single piece to place, which is a constraint that propagates hard and shows up as rejected maps rather than as an error.

## Closure

Every socket can be presented on every edge, so nothing offers a connection that cannot be taken. The set is closed; what it lacks is shapes, listed under Corners above.
