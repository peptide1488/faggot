   Divine Smite, Divine Strike, Colossus Slayer, Hurl Through Hell) via shared
   `attackRiderOptions`/`applyAttackRiders`, so QB and player-net stopped diverging.

3. **v120.201** — Damage-type threading through `applyHp` (Heavy Armor Master's flat reduction,

4. **v120.202** — **Armor-proficiency penalties.** New `ARMOR_PROF` class table + `armorProficient`.
   Disadvantage on Str/Dex attack rolls (via `Engine.hitResult`, the one shared resolver) and

5. **v120.203** — **Ritual casting.** `RITUAL_SPELLS`/`RITUAL_CASTERS`/`canRitualCast`. Bard/

   no slot and no action cost. New "🕯️ Cast as Ritual" checkbox in `castModal`. **Known gap:**

   doesn't read the checkbox — not wired yet.
6. **v120.204** — **Healer's Kit charges.** Real 10-use consumable (`c.healerKitCharges`, lazy
   default). `maneuverStabilize` gained `opts.kit`: skips the Medicine roll entirely (auto-
   succeeds, PHB tool rule), and the Healer feat adds +1 HP, correctly relayed to the target's
   own device in player-net via the existing stabilize/stabilized network messages.

All of the above: tests added to `rules-test.js` (705 assertions passing as of v120.204),

## Conventions to keep following (see `CLAUDE.md` for the full version)

- One shared function across QB/DM-hosted/player-net — never a per-mode duplicate. Branch inside
  via the adapter or a presence check (`ad.checkSubject`, `if(c){...} else {...}`), never `dmX`/
  `qbX` twin functions.
- Every rules change gets a `rules-test.js` assertion. Run `node rules-test.js 2>&1 | tail -3`
  after edits; widen only on failure.
- Version hygiene: bump `APP_VERSION` in `index.html` AND `CACHE` in `sw.js` together, every ship.
- AUDIT.md gets a section per system, following the exact style already in the file (context →
  what was built → what's honestly still missing → test count).
- Git hygiene: stage only the touched `dnd-character` files by explicit path (never `git add -A`
  — there's a large unrelated uncommitted pile in sibling directories like `iso3d-engine`). Push
  to BOTH `iso3d-engine` and `claude/elegant-bohr-zx67jk` (the actual Pages-deploy branch), and
  verify with the GitHub API SHA check, not raw.githubusercontent.com (which has a multi-minute
  CDN lag):
  ```
  curl -s "https://api.github.com/repos/peptide1488/faggot/commits/claude/elegant-bohr-zx67jk" | grep -m1 '"sha"'
  ```
